# Rule Breaker

A mobile-first reaction game prototype.

## Run locally
Open index.html in a browser, or serve the folder with any static web server.

## Deploy
This is a static HTML/CSS/JS game and can be deployed directly to Vercel, Netlify, GitHub Pages, etc.

## Current features
- 10 rules
- 3 lives
- Increasing speed
- Score and local best score
- Mobile touch support
- Responsive neon UI
- No external API/dependency
